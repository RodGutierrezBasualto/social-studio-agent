---
name: Learning
description: What qualifies as a durable learning worth remembering.
load_when: always
---

- Save a learning only when it is reusable in a future run. One-off facts about a single post are not learnings.
- A good learning is specific and testable: "first-person client stories outperform industry commentary on LinkedIn" beats "post engaging content".
- Require evidence. Claim a pattern only when at least two posts or an explicit user instruction support it, and set confidence accordingly.
- Record failures as clearly as wins. Knowing what flopped is worth as much as knowing what worked.
- When the user tells you a rule directly ("always X", "never Y", "remember that Z"), save it immediately as a preference.
- Do not restate an existing learning. If it is already known, the memory layer bumps its weight instead.
- Never fabricate performance numbers to justify a learning.
